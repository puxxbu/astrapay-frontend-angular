# Preview Simple Notes Frontend

## Cara Menjalankan Proyek

### 1. Install Dependencies

Pastikan **Node.js** dan **npm** sudah terinstal.  
Buka terminal di folder proyek dan jalankan:

```bash
npm install
```

### 2. Jalankan Backend

Jalankan terlebih dahulu **backend springboot API** yang berjalan di `http://localhost:8000`  
(sesuai konfigurasi di `src/app/app.ts`).  
Pastikan server backend Anda sudah aktif sebelum melanjutkan.

### 3. Jalankan Server Pengembangan (Frontend)

Gunakan salah satu perintah berikut:

```bash
npm start
```

Atau:

```bash
ng serve
```

### 4. Buka Aplikasi

Buka browser Anda dan akses:  
 [http://localhost:4200/](http://localhost:4200/)  
Aplikasi akan otomatis **reload** jika Anda mengubah file sumber.
